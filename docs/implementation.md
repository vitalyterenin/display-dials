# Реализация Display Dials 0.2.0

## Цель и текущий статус

Два регулятора для встроенного XDR-экрана MacBook Pro: теплота и усиление яркости.
Без исключений для приложений, расширенного управления мониторами и телеметрии.
Night Shift проверен пользователем в 0.1.0. Усиление остаётся экспериментом:
**абсолютный прирост яркости по сравнению с исходным режимом ещё не подтверждён**.

Название можно изменить через AppIdentity, Package.swift и metadata в build-app.sh.

## Путь вывода

`BoostController` запускает текущий executable с `--boost-worker`. Основное приложение
не владеет окнами усиления. Через stdin оно отправляет JSON heartbeat каждые 250 мс;
дочерний процесс возвращает состояние через stdout. Неверные сообщения отклоняются.

`HDRRenderer` рисует однородные RGBA16Float-поверхности в extended linear sRGB.
Небольшой HDR-маркер запрашивает у macOS запас EDR. Десктоп остаётся с коэффициентом
1 до появления фактического headroom. Затем отдельный слой использует композицию
`multiply`. Это экспериментальное поведение композитора macOS, не документированный
Apple API повышения яркости всего рабочего стола. Исходный код чужих renderer'ов
в проект не включён; реализация написана отдельно.

Нет вызовов изменения системной яркости, gamma-таблиц, пресетов или автояркости.
Окна пропускают мышь, не становятся key/main, работают во всех Spaces и закрываются
при завершении процесса. Режим полного экрана ещё требует ручной проверки.

## Ограничения эксперимента

- Только встроенный экран Apple Silicon с potential EDR > 1, без зеркалирования.
- Не более 30 секунд вместе с подготовкой. Подготовка ограничена 5 секундами.
- Коэффициент 1.00–1.25, по умолчанию 1.10. Это не проценты физических нит.
- Вывод не превышает текущий headroom. После его снижения коэффициент не повышается
  автоматически, даже если запас восстановился; повысить может только новое движение
  ползунка. Потеря headroom полностью прекращает тест.
- Любая thermalState выше nominal останавливает тест. Это системный сигнал,
  **не датчик температуры панели**.
- Сон, блокировка/деактивация сессии, пробуждение, изменение топологии/режима дисплеев,
  сбой GPU и запуск известной конфликтующей утилиты прекращают тест.
- BetterDisplay, BrightIntosh и Vivid проверяются по запущенным приложениям.
  Это консервативная проверка: мы не умеем определять, включён ли в них буст.
- Отсутствие heartbeat дольше 1.5 секунды завершает worker. Родитель завершает worker,
  если тот не присылает отчёты дольше 2.5 секунды. Независимый от главного run loop
  таймер завершает worker спустя 35 секунд даже при зависшем GPU-вызове.
- Перезапуск, пробуждение и исправление причины остановки не возобновляют усиление.

Пределы 1.25/30 секунд не являются доказанными безопасными значениями ресурса панели.
Системные защиты не обходятся, но нулевое влияние повышенной яркости на нагрев,
энергопотребление и старение не обещается. Постоянный режим не включён.

## Night Shift

`NightShiftBridge` изолирует private CoreBrightness API. Проверяются сигнатуры,
размер и выравнивание структуры. Совпадение ABI не гарантирует совместимость будущих
версий macOS. Изменения глобальные, применяются только по действию пользователя,
сохраняются после выхода. Системное расписание не меняется. Уровень 0–100% не
представляет калиброванную цветовую температуру в K.

## Что проверено 2026-10-30

На Apple M1 Pro, macOS 27.2, Swift 6.4.2 / Command Line Tools:

- 14 тестов политики и состояния: лимит, NaN/Infinity, время, heartbeat, готовность
  GPU, нагрев, сон, смена дисплея, конфликт, потеря headroom и отсутствие автовозврата.
  Эти тесты моделируют условия, а не нагревают реальный экран.
- Offscreen GPU check: float-значение 1.10 сохранилось как 1.099609375 (точность FP16).
  Экран при этой проверке не изменяется.
- IPC без окон: EOF, неверный JSON и нулевой коэффициент отклоняются до создания renderer.
- Интеграционный `--controller-check`: реальный контроллер запускает worker с одним
  HDR-маркером, получает active, останавливает его через 3 секунды и получает off.
- Release bundle 0.2.0 проходит проверку подписи и smoke test. Проверен PNG-рендер
  обновлённой панели. При старте тест усиления не включается.
- Живые тесты с одним маленьким HDR-маркером, **без слоя на рабочем столе**:
  EOF, прекращение heartbeat при открытом канале, SIGKILL и полный 30-секундный таймер.
  Проверены отчёты и завершение процессов. Физическая яркость после SIGKILL не измерялась.
- Полноэкранная проба ×1.05: Metal рисовал кадры; пользователь не заметил разницы.
- Проба правой половины ×1.20: пользователь увидел более светлую правую часть,
  затем отметил, что эффект может быть затемнением левой, а не ростом правой.
  **Первоначальный вывод о доказанном усилении отозван.**
- При пробе только HDR-маркера CoreDisplay user/linear/dynamicLinear остались 1.0,
  current EDR изменился с 1 до 4. Эти getter'ы — программные показатели, не фотометр.
  Они не доказывают неизменность светового выхода SDR-пикселей.

## Следующая проверка

Сравнивать один и тот же статичный участок до включения, при включении и после
выключения всего эффекта. Половины экрана показывают только относительный контраст.
Для объективного заключения нужны измерения яркости колориметром/люксметром при
неизменной геометрии или хотя бы внешняя камера с зафиксированной экспозицией для
относительного сравнения. Скриншоты, EDR headroom и float-буфер физический свет не меряют.

До постоянного режима остаются: абсолютный прирост; отсутствие нежелательного
затемнения SDR; цвет и HDR-видео; полноэкранные Spaces; ручная проверка сна/блокировки;
длительный нагрев и энергопотребление. Не увеличивать пределы только ради заметности.

## Команды разработчика

```sh
bash scripts/test.sh
swift run DisplayDials --renderer-check
python3 scripts/check-worker.py
# Только явно: краткие живые HDR-пробы, включая 30-секундный TTL:
python3 scripts/check-worker.py --live
bash scripts/build-app.sh
```

`--boost-worker --compare` ограничивает диагностический слой правой половиной;
`--boost-worker --trigger-only` рисует только HDR-маркер. Обоим нужны heartbeat через
stdin, и оба подчиняются тем же ограничениям, включая конфликты и температуру.
